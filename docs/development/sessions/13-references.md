# 13회 · 문장 연결·역링크·복선 회수

**작가가 얻는 결과** · 설정에서 근거 문장으로 돌아가고 아직 회수하지 않은 복선만 본다.

## AI 작업 지시

이 문서 전체를 이번 회차의 구현 지시로 사용해라. 저장소의 기존 규칙과 `docs/development/FOUNDATIONS.md`, `WORKSPACE_FORMAT.md`, `QUALITY_GATES.md`, `PROGRESS.md`를 확인하고 실제 코드 상태와 대조해라. 네 공통 문서는 모두 `docs/development/` 아래에 있다. 이미 구현한 부분은 동작을 검증해 재사용하고 이번 범위의 코드 수정, 테스트, 인계까지 수행해라.

**시작 조건** · 06회 과거판, 08회 카드, 09회 사건, 12회 대목 이동을 사용한다.

### 구현 순서

1. 내장 원고의 선택 문장 → 설정 카드/사건 연결을 만든다. 대상에서 원문으로 돌아가는 역링크와 어느 회차·판의 문장인지 표시한다. 선택 위치·원문·전후 문맥·기준판을 보관한다.
2. 현재 원고에서 문단이 이동하면 지문과 문맥으로 다시 찾는다. 후보 하나일 때만 자동 연결하고 같은 문장이 여러 개면 그 앞뒤를 보여준다. 사라지면 기준판 열기/수동 재연결을 제공한다.
3. 복선에는 제목, 등장 문장, 미회수/회수, 선택한 회수 지점을 저장한다. 목록에서 열린 것만 조회하고 다시 열 수 있게 한다. 원문 바뀜 표시와 복선 상태는 독립적으로 갱신한다.
4. 회차 커밋 뒤 연결 자료의 기준판과 비교하여 검토 표시를 붙인다. 자료별 ‘이대로 확인’과 ‘다시 연결’을 구현하고 관계의 역방향 목록은 원본 링크에서 파생한다.
5. 복선의 열기·회수·다시 열기를 회차·순서가 있는 이력으로 남긴다. 기준 회차까지의 마지막 상태로 과거 미회수 목록을 만들 수 있게 한다. 공개 회차가 없는 상태 전환은 작가용 목록에서만 쓴다.

### 완료 기준

- [ ] **S13.A** · 7화 편지를 32화 발신자 공개로 회수, 미회수 필터에서 사라짐, 다시 열면 나타남. 재실행 후 동일하다.
- [ ] **S13.B** · 원문 앞 문단 추가·다른 위치로 이동·완전 삭제·같은 인용 두 군데·이모지 포함 선택 범위를 시험한다.
- [ ] **S13.C** · 현재 원문에서 못 찾아도 옛 확정판 문장을 볼 수 있다. 검토 한 항목을 해제해도 다른 요약·사건의 경고는 남는다.

### 추가 지시 (계획 변경분)

원문과 채택 이유는 `docs/development/PLAN_CHANGES.md`에 있다.

- CH3 몫과 최종 검증 · 문장 링크가 생기면 같은 ‘연결된 회차’ 목록에 근거로 추가한다. 같은 별칭을 쓰는 두 카드가 있어도 본문 문자열 적중만으로 어느 카드에도 연결을 자동 생성하지 않는다. 카드명 변경 후에도 기존 연결은 ID로 열린다.

추가 완료 기준

- [ ] **S13.D** · 2화에는 ‘린’ 편지만(연결 없음), 3화에는 ‘그 아이’ 문장의 서린 카드 링크만 → 이름·별칭 검색은 2화, 연결 조회는 3화. 3화 사건을 추가하면 3화 한 행에 근거 두 개. 카드명 변경 후에도 같은 결과.

### 회차를 닫을 때

현재 회차에서 추가한 기능을 앱의 정상 진입점으로 한 번 따라가라. 실제로 실행한 명령·환경·결과를 `docs/development/PROGRESS.md`에 적고, 실행하지 못한 실기기 검사는 필요한 환경과 함께 ‘미검증’으로 남겨라. 임시 작품·합성 원고로 테스트하고 사용자의 실제 원고를 바꾸지 마라.

**이번 회차 인계 항목** · 인용 재탐색 순서, 불확실 상태의 화면, 복선과 역링크 표본 및 기대 결과.

최종 답변에는 작가가 따라 할 확인 절차, 변경 파일, 완료 기준별 통과/실패/미검증과 남은 영향을 적어라. 다음 개발 회차는 별도 지시에서 진행한다.
