# 10회 · 회귀 구간 링크와 그 시점의 능력

**작가가 얻는 결과** · 300~350화만 보는 링크를 저장하고 독자가 25화까지 아는 능력을 조회한다.

## AI 작업 지시

이 문서 전체를 이번 회차의 구현 지시로 사용해라. 저장소의 기존 규칙과 `docs/development/FOUNDATIONS.md`, `WORKSPACE_FORMAT.md`, `QUALITY_GATES.md`, `PROGRESS.md`를 확인하고 실제 코드 상태와 대조해라. 네 공통 문서는 모두 `docs/development/` 아래에 있다. 이미 구현한 부분은 동작을 검증해 재사용하고 이번 범위의 코드 수정, 테스트, 인계까지 수행해라.

**시작 조건** · 09회에 하나의 사건이 여러 보기에서 같은 ID로 열린다.

### 구현 순서

1. 필터에 회차 범위, 작중 범위·트랙, 태그 포함/숨김, 대상 타임라인을 추가한다. 복수 포함 태그는 기본 OR, 숨김은 우선 적용으로 규칙을 표시한다. 필터 해제·명시적인 사건 삭제를 구분한다.
2. 작품 내부 링크 ‘회귀편’을 만든다. 불변 viewId와 조건을 저장하고 재조회한다. 상위 타임라인에 하위 보기 링크를 붙인다. 링크 따라가기는 한 번에 한 단계, 뒤로 가기에서 필터와 스크롤을 복구한다. 자기참조나 순환 때문에 전체 뷰를 재귀 로드하지 않는다.
3. 상태 변화를 entity/property/value로 저장하고 ‘독자 공개 회차 기준’은 공개된 사건만 회차순, ‘작중 기준’은 같은 트랙의 시간순으로 마지막 값을 계산한다. 속성이 여럿이면 속성별 마지막 값이다. 두 조건 동시에는 교집합 후 사용자가 선택한 우선 축과 동률 규칙으로 결정한다.
4. 고정된 ‘25화 기준’ 뷰에 최신 인물 카드의 미래 자유 메모가 섞이지 않게 한다. 현재 전체 설정 열기는 별도 명시 동작이다. 아직 값이 없는 속성은 미기록으로 보여준다.

### 완료 기준

- [ ] **S10.A** · 299/300/327/350/351화 경계, 미정 좌표, 두 축 같은 순번, 다른 트랙을 포함한 fixture로 기대 ID와 상태를 대조한다.
- [ ] **S10.B** · 300~350화 링크 생성 뒤 327화 사건 추가 → 재조회에 포함. 태그 숨김 후 해제 → 원래 사건 수 복원. 링크 대상이 사라지면 원래 위치로 돌아갈 수 있다.
- [ ] **S10.C** · 327화에서 뒤늦게 밝혀진 작중 2일차 사건은 ‘25화까지 공개’에서 숨고 작중 2일차 모드에서 보인다. 교집합 모드에서는 숨는다.

### 회차를 닫을 때

현재 회차에서 추가한 기능을 앱의 정상 진입점으로 한 번 따라가라. 실제로 실행한 명령·환경·결과를 `docs/development/PROGRESS.md`에 적고, 실행하지 못한 실기기 검사는 필요한 환경과 함께 ‘미검증’으로 남겨라. 임시 작품·합성 원고로 테스트하고 사용자의 실제 원고를 바꾸지 마라.

**이번 회차 인계 항목** · 저장 뷰 직렬화, 각 모드 필터 및 동률 규칙, 미래 정보가 포함되지 않음을 증명하는 데이터.

최종 답변에는 작가가 따라 할 확인 절차, 변경 파일, 완료 기준별 통과/실패/미검증과 남은 영향을 적어라. 다음 개발 회차는 별도 지시에서 진행한다.
