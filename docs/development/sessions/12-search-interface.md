# 12회 · 빠른 열기와 본문 대목 검색

**작가가 얻는 결과** · 단축키로 351화·인물·회귀편을 열고, 사라진 문장을 옛 원고에서 다시 찾는다.

## AI 작업 지시

이 문서 전체를 이번 회차의 구현 지시로 사용해라. 저장소의 기존 규칙과 `docs/development/FOUNDATIONS.md`, `WORKSPACE_FORMAT.md`, `QUALITY_GATES.md`, `PROGRESS.md`를 확인하고 실제 코드 상태와 대조해라. 네 공통 문서는 모두 `docs/development/` 아래에 있다. 이미 구현한 부분은 동작을 검증해 재사용하고 이번 범위의 코드 수정, 테스트, 인계까지 수행해라.

**시작 조건** · 11회의 실제 색인 결과와 10회의 저장 보기 링크가 있다.

### 구현 순서

1. Ctrl+P는 번호 완전 일치, 제목·별칭 완전 일치, 접두, 부분 일치 순서를 명시한다. 종류·회차·경로로 동명이인을 구별한다. 키보드만으로 이동·열기·취소를 끝낼 수 있게 한다.
2. Ctrl+Shift+F에 문서 종류, 회차 범위, 태그, 이력 포함을 둔다. 결과마다 종류·회차/판·앞뒤 문장·강조를 표시하고 결과가 많으면 첫 페이지부터 읽게 한다. 과거판 적중은 읽기 전용 해당 판을 연다.
3. 긴 검색은 취소 가능하게 하고 이전 요청 결과가 현재 검색어를 덮지 않게 한다. IME 조합 중 Enter는 검색 결과를 열지 않는다. 결과 이동과 뒤로 가기에서 검색어·필터·스크롤을 보존한다.
4. 검색 0건, 색인 중 부분 결과, 캐시 손상 후 재생성, 클릭 직전 원고가 변해 위치를 다시 찾아야 하는 경우의 실제 상태를 구현한다.

### 완료 기준

- [ ] **S12.A** · Ctrl+P에서 ‘351/서린/린/회귀편’이 각각 기대 대상으로 간다. Ctrl+Shift+F로 동일 문자열의 본문 결과도 찾는다.
- [ ] **S12.B** · r2에서 사라진 r1 문장을 이력 포함 전후로 비교해 문서/판/강조 위치를 확인한다. 이모지가 앞에 있어도 정확한 한국어 문장이 강조된다.
- [ ] **S12.C** · ‘불’ 입력 직후 더 긴 검색어 입력 → 앞 요청이 늦게 끝나도 긴 검색어 결과가 유지된다. 키보드로 돌아오면 필터와 선택이 남는다.

### 회차를 닫을 때

현재 회차에서 추가한 기능을 앱의 정상 진입점으로 한 번 따라가라. 실제로 실행한 명령·환경·결과를 `docs/development/PROGRESS.md`에 적고, 실행하지 못한 실기기 검사는 필요한 환경과 함께 ‘미검증’으로 남겨라. 임시 작품·합성 원고로 테스트하고 사용자의 실제 원고를 바꾸지 마라.

**이번 회차 인계 항목** · 검색 단축키, 정렬·필터 계약, 문단 위치 해석, 17회가 호출할 입력→첫 결과 측정 지점.

최종 답변에는 작가가 따라 할 확인 절차, 변경 파일, 완료 기준별 통과/실패/미검증과 남은 영향을 적어라. 다음 개발 회차는 별도 지시에서 진행한다.
